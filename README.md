# R9OOF.COM

Сайт любительской радиостанции R9OOF: DX-экспедиции, хроника RDA, детская
радиошкола, трансляции и инженерный справочник.

Собран на [Astro](https://astro.build). Результат сборки это обычные статические
страницы, поэтому сайт работает быстро и не требует сервера приложений.

## Запуск

Нужен Node.js версии 24 или новее.

```
npm install
npm run dev
```

Сервер разработки поднимется на `http://localhost:4321`.

## Разделы

| Адрес | Раздел |
| --- | --- |
| `/` | главная страница-визитка |
| `/dx` | DX-экспедиции |
| `/rda` | хроника выездов RDA |
| `/school` | детская радиошкола и трансляции из класса |
| `/live` | трансляция экрана рабочего места |
| `/handbook` | инженерный справочник и мануалы |
| `/beginners` | материалы для начинающих |

## Ветки

`main` это боевой сайт, `TEST` это разработка. Изменения делаются в `TEST` и
попадают в `main` слиянием после проверки сборки.

Подробные правила работы описаны в [CLAUDE.md](CLAUDE.md).
