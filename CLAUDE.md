# R9OOF.COM — рабочие правила проекта

Сайт любительской радиостанции R9OOF. Статическая сборка на Astro, без базы данных
и без серверной части.

## Ветки и папки

| Ветка | Локальная папка | Назначение |
| --- | --- | --- |
| `main` | `02 WEB` | боевой сайт, публикуется автоматически |
| `TEST` | `02-1 TEST WEB` | разработка, отладка, правки |

Обе папки это git worktree одного репозитория `serg-tm-usa/R9OOF.COM`. Общая база
git лежит в `02 WEB/.git`, поэтому ветки не расходятся и не дублируются.

Работаем всегда в `02-1 TEST WEB` на ветке `TEST`. В `main` изменения попадают
только слиянием, после проверки сборки.

## Команды

```
npm install      # один раз после клонирования
npm run dev      # локальный сервер разработки
npm run build    # сборка в dist, обязательна перед слиянием в main
npm run preview  # просмотр готовой сборки
```

## Структура

```
src/
  pages/          маршруты сайта, имя файла равно адресу страницы
  layouts/        общий каркас страницы
  components/     повторно используемые куски разметки
  content/        материалы в markdown
    dx/           отчёты об экспедициях
    rda/          выезды на активацию районов
    handbook/     статьи инженерного справочника
  data/           настройки трансляций
  lib/            вспомогательные функции
  styles/         глобальные стили, вся палитра в одном файле
public/           файлы, попадающие на сайт как есть: картинки, иконки
```

## Как добавить материал

Положить markdown-файл в нужную папку внутри `src/content/`. Имя файла становится
адресом страницы. Обязательные поля описаны в `src/content.config.ts`, при ошибке
сборка падает с понятным сообщением.

Незаконченный материал помечается `draft: true` и на сайт не попадает.

## Правила

- Язык интерфейса и материалов русский.
- Цвета и шрифты меняются только в `src/styles/global.css`, не в отдельных страницах.
- Разделы меню перечислены в `src/components/Header.astro`, одним списком.
- Ссылки на трансляции хранятся в `src/data/streams.ts`, не разбросаны по страницам.
- Перед слиянием в `main` обязательно проходит `npm run build`.
