## Что такое MCP, коротко

Model Context Protocol — открытый стандарт, по которому модель подключается к внешним инструментам, данным и сервисам. Без него модель знает только то, чему училась, и не видит ни файлов, ни баз, ни API.

Три роли:
- **Хост** — программа, где работает модель (у нас Claude Code, чаты claude.ai).
- **Клиент** — встроенная в хост часть, которая держит соединение с сервером и передаёт запросы и ответы.
- **Сервер** — отдельная программа, которая даёт доступ к конкретному инструменту или данным и говорит по протоколу.

Сервер отдаёт три вида вещей:
- **Инструменты (tools)** — действия: запустить сканер, проверить адрес, отправить пост.
- **Ресурсы (resources)** — данные для чтения: файлы, таблицы, страницы.
- **Промты (prompts)** — готовые инструкции и шаблоны.

Схема работы: модель шлёт запрос («дай данные») → MCP направляет его нужному серверу → сервер возвращает результат модели.

## Что из этого полезно нам

1. **Единый способ подключения.** Сейчас у нас в планах инструменты подключаются кто как: скилл, плагин, скрипт, GitHub Action, внешняя панель. MCP даёт один стандарт: любой проект подключает любой инструмент одинаково, и один сервер служит всем чатам сразу.
2. **Тройка «инструменты, ресурсы, промты» совпадает с нашей структурой агентов.** В `humanizer2/agents.md` у каждого агента есть действия (инструменты), память и факты (ресурсы), контекст (промты). MCP описывает то же самое на уровне протокола.
3. **Серверы уже есть у инструментов, которые мы выбрали:**
   - Cloudflare Radar MCP — проверка адресов (в плане установки).
   - humanizer-ru — свой MCP-сервер к сканеру (`scripts/humanizer_metrics/mcp_server.py`).
   - agent-memory — `mem-mcp` для памяти (кандидат).
   - vgpu — MCP с документацией (песочница).
   - GitHub MCP — уже используется в этой сессии.
4. **Разделение хост/сервер защищает проекты друг от друга.** Чат R9OOF.COM, которому код запрещён, может только читать ресурсы и звать инструменты; проект humanizer может их писать. Права задаются на сервере, а не на честном слове.
