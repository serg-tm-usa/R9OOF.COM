# Общее правило: честность отчётов и измерений

1. Статус пишется словами, которые нельзя перепутать: посмотрел / изменил локально / проверил / закоммитил / отправил / не делал.
2. Вердикт одной строкой → блокеры → проверенные улики → следующее действие.
3. Метрика без воспроизводимого бенча не существует; цифры «заявлено» и «измерено» пишутся раздельно; три прогона в одном разбросе — минимум для «улучшения».
4. `NOT_RUN` пишется честно там, где не меряли; «не запустился» ≠ «чисто»; проверка нуля элементов падает.
5. Отрицательные результаты публикуются; «не сработало и почему» — обязательный раздел сводки сессии.
6. Ограничения результата перечисляются явным списком: что не читалось, что не проверялось.
7. Оценочная лексика в докладе агента запрещена; наблюдение, не оценка; хвалить ради баланса нельзя («ноль сильных сторон — допустимо»).
