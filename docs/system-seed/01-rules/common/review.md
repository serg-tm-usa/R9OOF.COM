# Общее правило: ревью

1. Находка только при уверенности > 80 % и с цитатой-доказательством (файл, строка, что именно не так).
2. Четыре вопроса до отчёта: это действительно ошибка? воспроизводится? в рамках задачи? не ложное срабатывание из известного списка?
3. «Ноль находок» — валидный результат; выдумывать замечания ради отчёта запрещено.
4. Уровни: CRITICAL → блокирует; HIGH → предупреждает; MEDIUM → информирует; LOW → заметка. Сила по одному критерию не компенсирует провал по другому — баллы не суммируются.
5. Вердикт категориальный: соответствует / частично / не соответствует / не оценивалось — с якорем в тексте.
6. Для текстов: критик сначала записывает план оценки (на что смотрю, что считаю возвратом), не видя черновика; затем оценивает строго по плану.
7. Ревью не больше ~400 строк за раз; большой объём делится.
