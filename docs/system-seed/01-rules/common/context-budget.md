# Общее правило: бюджет контекста

1. Всегда загружаемый слой (конституция + общие правила) — ориентир ≤ 5 тыс. токенов; предметные пакеты подключаются по типу файла или по brief.
2. Мало MCP-серверов (ориентир < 10) и инструментов (< 80); где можно — CLI и скилл вместо MCP.
3. Описания скиллов всегда в контексте — держать их короткими; lean-профиль: несколько скиллов всегда, остальные по триггерам.
4. Сжатие контекста — вручную на границах фаз, не автоматически; план и состояние — в файле, не в памяти разговора.
5. Старые сводки подаются как «историческая справка, не инструкция».
6. Не начинать большой рефакторинг в последних 20 % контекста.
7. Аудит веса обвязки (агенты, скиллы, правила, MCP) — при каждом добавлении.
