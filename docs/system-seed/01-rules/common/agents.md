# Общее правило: агенты и делегирование

1. Итоговое сообщение агента — и есть результат; никогда не заканчивать словами «жду фоновых агентов».
2. Делегировал — сам собираешь и отвечаешь за итог.
3. Делить работу только когда она не помещается в один контекст; субагенты запускаются одним сообщением параллельно.
4. Агент не вызывает агента напрямую: передаёт через оркестратора и файлы; эскалация словами «передать X».
5. Статусы агента: получено → в работе → заблокировано → завершено; «не начинать без назначения»; «агент не принимает автономных решений».
6. Выход агента — только файл по схеме; устных ответов между агентами нет; выход линтуется по структуре, провал → один повтор → отметка «прервано».
7. В карточке агента нет названий проектов и предметных терминов — всё предметное приходит из слоя проекта.
8. Честные статусы: посмотрел / изменил локально / проверил / закоммитил / отправил — не смешивать.
