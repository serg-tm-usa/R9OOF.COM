## Кандидаты в правила (из пары 01, предварительно)
1. Шутка принимается, если опирается на факт из жизни автора; шутка «из воздуха» вырезается.
2. Профессиональную деталь не упрощать: читатель-коллега должен узнать своё.
3. При переписывании по жалобе «то же самое» менять конструкции, а не слова; писать с нуля.
4. Церковная лексика только всерьёз или в шутке над собой.
5. Автор удлиняет фразы и делает их неровнее, чем машина. Целевой разброс длины фраз ≥ 7.
