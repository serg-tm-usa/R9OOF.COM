# Пара 01 · Отчёт R8PG/P о выезде на ТО-24

Дата: 2026-10-04.

## Статус: переклассифицирована 2026-10-04

По слову владельца `owner-final.md` — не его текст, а черновик агента с его правками. Поэтому эта пара **не эталон голоса владельца** и для профиля не используется.

Чем она остаётся полезна:
- Пара «машина → машина, поправленная владельцем»: показывает, что именно владелец вырезает и вставляет в машинный текст. Это материал для Аналитика (правила про шутки, детали, церковную лексику), но не для Профилировщика.
- Пример формата пары для корпуса.

## Файлы
- `machine-draft.md` — черновик агента (версия 6) по промту владельца.
- `owner-final.md` — тот же текст после правок владельца (с корректорской правкой опечаток).

## Что владелец изменил (для Аналитика)
- Добавил свою биографию и опыт там, где у машины были общие слова: правило старых охотников, «человек из леса», операция.
- Убрал часть шуток машины, добавил свои.
- Вернул профессиональные детали: надставка мачты, «as is», «восьмёрка» на RigExpert, SN, перемычки на 20 минут.
- Оставил свои цифры, даже если они расходились с машинными.
- Православное оставил только всерьёз или в шутке над собой.
