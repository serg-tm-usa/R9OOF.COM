## Нужно от владельца
1. Список стилей и согласие, что живые авторы идут только профилем по описанию.
2. 3–5 своих текстов для эталона.
3. Режим по умолчанию: лёгкий или полный.
4. Снятие запрета на код перед этапом 2.

## Риски
- Самообучение без контрольного набора ухудшит скилл. Этап 1 раньше этапа 5.
- Детекторы ошибаются в обе стороны. Цель — оценка владельца и судьи, не «0% ИИ».
- Полный цикл дорог по токенам. Лёгкий режим обязателен.
