## Передача наработок в среду
1. Проект-исполнитель открывает `docs/humanizer2/` из ветки `TEST`.
2. Читает по порядку: `MEMORY.md` → `CONTROL.md` → `PLAN.md` → `agents.md` → `metrics.md` → `rules-ru.md` → `profiles/` → `corpus/` → `memory/`.
3. Первые действия исполнителя: принять тексты владельца и авторов; поставить сканер humanizer-ru; снять профиль владельца; завести папки агентов на `T:`.
4. Решения, принятые исполнителем, он записывает в свою память; сюда возвращаются только те, что меняют план.

## Что проект-исполнитель получает от владельца напрямую

## Риски
- Самообучение без контрольного набора ухудшит скилл. Этап 1 раньше этапа 5.
- Детекторы ошибаются в обе стороны. Цель — оценка владельца и судьи, не «0% ИИ».
- Полный цикл дорог по токенам. Лёгкий режим обязателен.
