# Humanizer 2 · машинная память проекта

Отдельная память проекта, по тем же правилам, что `docs/ideas.md`: ничего не удалять, отменённое помечать с датой и причиной. Любая сессия, работающая над Humanizer 2, сначала читает этот файл и `CONTROL.md`, потом `PLAN.md`.

Формат: дата · что решено или сказано · кем · статус.

## Решения владельца

### 2026-10-04 · Переработать скилл в связку агентов · решено
- Несколько агентов с разными ролями вместо одного скилла (см. `agents.md`).
- Обязательно самообучение с машинным контролем (см. `CONTROL.md`, ворота).
- Научить стилям популярных писателей.

### 2026-10-04 · Живые авторы только профилем · предложено агентом, ждёт подтверждения владельца
- Тексты живых и охраняемых авторов не загружаются, не анализируются, не перерабатываются.
- Профиль составляется по описанию стиля. Примеры пишутся свои.
- Общественное достояние (Чехов, Зощенко, Бунин, Ильф и Петров, Гоголь) используется целиком.

### 2026-10-04 · Запрет на код действует · решено владельцем
- Всё в папке `docs/humanizer2/` — документы. Скилл `.claude/skills/humanizer/` не трогать до снятия запрета.

### 2026-10-04 · Отдельный план = отдельная память и контроль · правило владельца
- Каждый отдельный план ведётся в своей папке с тремя файлами: `PLAN.md` (что делать), `MEMORY.md` (что решено и сказано), `CONTROL.md` (как проверяется).
