# Метрики для критика и ворот самообучения

Что измеряется у любого текста. Нормы берутся из профиля голоса, не из общих цифр.

| № | Метрика | Как считать | Ориентир (профиль владельца) |
| --- | --- | --- | --- |
| M1 | Разброс длины фраз (burstiness) | сигма числа слов во фразах | ≥ 7 |
| M2 | Размах длины фраз | макс − мин слов | ≥ 35 |
| M3 | Разброс длины абзацев | сигма слов в абзаце | ≥ 30 |
| M4 | Плотность тире | тире на 100 фраз | 0 для владельца; для других профилей по образцу |
| M5 | Плотность двоеточий | двоеточий на 100 фраз | около 20 для владельца |
| M6 | Отглагольные существительные | слов на -ание/-ение/-ация/-ость на 1000 слов | ≤ 3 |
| M7 | Доля глаголов | % глаголов от слов (нужен морфоанализатор, pymorphy3 или аналог) | снять по корпусу |
| M8 | Доля списков | строк-списков к абзацам | 0 в рассказе |
| M9 | Штампы | число попаданий по спискам §12, §32–§34 | ≤ 1 на 500 слов |
| M10 | «Не X, а Y» и тройки | число на текст | ≤ 1 на 1000 слов |
| M11 | Концовки-афоризмы | абзацев, заканчивающихся обобщением без факта | 0 |
| M12 | Повтор мысли | пар соседних фраз с одним смыслом (судья) | 0 |
| M13 | Сохранность фактов | все строки `facts.md` найдены в тексте; добавленных нет | 100% / 0 |
| M14 | Оценка судьи стиля | 1–10 вслепую | ≥ 8 |
| M15 | Внешний детектор | доля «красных» фрагментов (GigaCheck, text.ru) | подсказка, не порог |

Ворота самообучения: кандидат в правило принимается, если на контрольном наборе ни одна из M1–M14 не ухудшилась и M14 не упала. M15 только наблюдается.

Первые измерения (2026-10-04) по паре 01: владелец M1 = 7,2, M2 = 39, M3 = 34, M4 = 0, M5 = 20, M6 = 2,5. Машинные черновики: M1 = 6,1–6,5, M2 = 28, M3 = 25–27, M5 = 13–15, M6 = 1,4–3,9.
