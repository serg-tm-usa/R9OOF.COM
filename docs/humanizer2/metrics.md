# Метрики для критика и ворот самообучения

Решение владельца 2026-10-04: сканер берём готовый, из ilyautov/humanizer-ru (MIT, v3.31.3, `skills/humanizer-ru/scripts/scan.py`, зависимости `razdel` и `pymorphy3`). Свой сканер не пишем. Ниже наши метрики и чем в сканере они закрываются.

| № | Метрика | Модуль сканера humanizer-ru | Ориентир |
| --- | --- | --- | --- |
| M1 | Разброс длины фраз (burstiness) | `burstiness.py` → `rhythm` | из профиля голоса |
| M2 | Размах длины фраз | `burstiness.py` | из профиля |
| M3 | Разброс длины абзацев | `structure.py` → burstiness абзацев | из профиля |
| M4 | Плотность тире | `burstiness.py` (типографика, `dash_ok` по жанру) | из профиля |
| M5 | Плотность двоеточий | нет в сканере; считать отдельно или отказаться | из профиля |
| M6 | Отглагольные существительные | `morphology.py` (существительные к глаголам, pymorphy3) | ≤ норма профиля |
| M7 | Доля глаголов | `morphology.py` | из профиля |
| M8 | Доля списков | `structure.py` → listicle-сигнатура | 0 в рассказе |
| M9 | Штампы и жёсткие запреты | `markers.py` → 67 признаков, 21 жёсткий запрет, жанровые исключения `--genre` | 0 жёстких; маркеры ≤ 1 на 500 слов |
| M10 | «Не X, а Y», тройки | `markers.py` (категории I, M) | ≤ 1 на 1000 слов |
| M11 | Концовки-афоризмы | `markers.py` (категория N: явная мораль в финале) | 0 |
| M12 | Повтор мысли | `repeats.py` (повтор фраз между абзацами) + Судья для смысловых повторов | 0 |
| M13 | Сохранность фактов | `facts.py` → факт-замок: цифры и имена до/после | 100% / 0 добавлений |
| M14 | Оценка судьи стиля | не сканер; агент Судья | ≥ 8 |
| M15 | Внешний детектор | не сканер; GigaCheck, text.ru | наблюдение |
| — | Балл чистоты 0–100 | `score.py` → `cleanliness_score` | «было N, стало M» в отчёте Критика |
| — | Лексическое разнообразие (MATTR) | `lexical.py` | из профиля |
| — | Обрыв на полуслове, Title Case | `structure.py` | 0 |

Что сканер не умеет: M5 (двоеточия), M14, M15, смысловые повторы. M5 решить на этапе 2: дописать пять строк или убрать метрику.

Нормы: не общие цифры, а значения из профиля голоса, снятые тем же сканером с образцов владельца. Пока профиля владельца нет (отменён 2026-10-04), Критик сравнивает только с жанровыми порогами сканера.

Ворота самообучения: кандидат в правило принимается, если на контрольном наборе ни одна из M1–M14 не ухудшилась, M13 = 100%, M14 не упала. M15 только наблюдается.

История: первые ручные измерения от 2026-10-04 (пара 01) отменены вместе с профилем владельца; сканер их заменит.
