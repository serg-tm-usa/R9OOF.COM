# pdf-visual · машинный контроль

## A. Контроль плана (каждая сессия исполнителя)
1. Прочитать `MEMORY.md`, `CONTROL.md`, `PLAN.md` до начала работы.
2. Чат R9OOF.COM меняет только эту папку и `docs/ideas.md`; код навыка не трогает никогда. Исполнитель меняет навык `pdf-markitdown` в своём месте, сюда дописывает результаты.
3. Сверить опись: `PLAN.md`, `MEMORY.md`, `CONTROL.md`. Отсутствие файла — остановка.
4. Решение владельца записывается в `MEMORY.md` в тот же день.
5. Каждое изменение папки — отдельный коммит в `TEST`.

## B. Критерии приёмки этапов
| Этап | Принят, когда |
| --- | --- |
| 0 | На вопросы 1–4 в `MEMORY.md` есть ответ владельца |
| 1 | Отчёт пробы содержит: число листов, секунд на лист при индексации, долю вопросов, где нужный лист в первой пятёрке (цель ≥ 8 из 10), долю верно прочитанных чисел с растра; всё на русских сканах владельца |
| 1а | Таблица «модель · секунд на лист · найдено в пятёрке · верно прочитано · размер индекса» минимум для двух моделей; выбор записан с причиной |
| 2 | Текст v07 содержит манифест плиток, три команды, изменения правил 2, 4, 5, 8, 8г, 9, 10; ни одно правило v06 не ослаблено (проверка построчно: что было запрещено, осталось запрещено) |
| 3 | Самотест визуального индекса проходит на эталонном листе с известным ответом; тяжёлые зависимости вне папки навыка; `serve` слушает только 127.0.0.1 (проверено командой) |
| 4 | Вся база проиндексирована; SHA-256 каждого исходника в индексе; подмена файла с тем же именем обнаруживается (проверка как в правиле 8г) |
| 5 | Журнал за месяц: число вопросов, найдено визуально / текстом / обоими / ни одним; решение владельца записано |

## C. Правила, которые нельзя нарушить при реализации
- Сканы и индекс не покидают машину владельца; облачный API PixelRAG не используется.
- Пакеты ставятся только после отчёта SkillSpector (правило 6 `checks.md`) и только из оригинальных источников.
- Найденный лист ≠ верный ответ: уровни достоверности v06 действуют; чтение чисел с растра требует второго взгляда.
- Индекс и модель хранятся с версией; индекс одной модели не используется с другой.
