# TODO проекта R9OOF.COM · с машинным контролем

Собран 2026-10-04 из решений в `docs/ideas.md` и `docs/humanizer2/`. Сводка по исполнителям и порядок чтения на среду — `docs/HANDOVER.md`. Этот чат (R9OOF.COM) код не пишет никогда и **работу другим чатам не назначает**: каждая строка ниже — предложение, колонка «Исполнитель» означает «кому предлагается», «Критерий приёмки» — «как этот чат предлагает проверять». Проектный чат сам решает, брать ли, как делать и с какой структурой; просьба лишь записать итог (взято / отклонено с причиной / переделано) в колонки «статус» и «проверено чем», чтобы ничего не потерялось (правило владельца 2026-10-05).

## Правила контроля

1. Каждая задача имеет: номер, источник решения (ссылка на раздел), исполнителя, критерий приёмки, статус, дату последнего изменения.
2. Статусы: `ожидает` · `в работе` · `на проверке` · `сделано` · `отложено` · `отменено`. Удалять строки нельзя; отменённое помечается с причиной.
3. Задача переходит в `сделано` только когда критерий приёмки подтверждён проверкой, записанной в колонке «Проверено чем».
4. В начале каждой сессии агент: читает этот файл; сверяет статусы с реальностью (ветка `TEST`, папки планов, слова владельца); расхождения правит в статусах, не в файлах проекта; записывает дату проверки в «Журнал проверок».
5. Новое решение владельца = новая строка в тот же день. Решение, меняющее задачу, = новая строка с пометкой «заменяет T-NN», старая помечается.
6. Исполнитель, закрывая задачу, приписывает ссылку на коммит, файл или отчёт. Без ссылки статус `сделано` не ставится.
