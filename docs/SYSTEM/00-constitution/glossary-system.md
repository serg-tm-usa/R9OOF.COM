# Словарь терминов системы

| Термин | Значение |
| --- | --- |
| якорь истины | решение владельца, записанное файлом в `03-memory/anchors/`; только добавление; новый якорь `supersedes` старый; якорь главнее любой памяти |
| слой проекта | всё предметное одного проекта (`brief`, `voice`, `glossary`, `facts`); подаётся агентам на вход, в универсальные слои не попадает |
| кандидат | предложенное правило в `05-gates/candidates/`; не действует, пока не прошло ворота и не утверждено владельцем |
| ворота | проверка кандидата на замороженном наборе: ни одна метрика не хуже, факты 100 %, затем слово владельца |
| ярус происхождения | откуда знание: наблюдённый факт (продвигаемо) или вывод по структуре (только наблюдение) |
| trust | owner / reviewed / unreviewed — кто подтвердил запись |
| честный статус | посмотрел / изменил локально / проверил / закоммитил / отправил / не делал |
| сайдкар | сгенерированный файл рядом с ручным (`*.generated.md`), никогда не поверх |
| брейншторм-чат | чат, который исследует инструменты и пишет предложения; ничего не меняет |
| пакет правил | предметный набор правил в `01-rules/packs/`, подключаемый по типу файла или по brief |
