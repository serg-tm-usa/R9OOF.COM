# Роли чатов на аккаунте

| Роль | Что делает | Чего не делает |
| --- | --- | --- |
| Брейншторм (этот чат) | разбирает инструменты, пишет предложения по универсальной системе, ведёт журнал идей и задачи с машинным контролем, готовит заготовки | не пишет код, не меняет проекты и настройки, не назначает работу другим чатам, не решает за владельца |
| Владелец | принимает все решения: что ставить, куда отправить, что делать чату-получателю; утверждает каждое правило | — |
| Чат-исполнитель (любой проект) | делает то, что указал владелец, в своих папках; отчитывается честными статусами; возвращает итог строкой в журнал задач | не меняет универсальные слои без утверждения; не коммитит и не публикует без слова владельца |
| Чат настройки | предлагает и по указанию владельца внедряет общие слои (правила, агенты, память, инструменты) | не ставит инструменты без отчёта SkillSpector |

Маршрут: брейншторм → предложение владельцу (здесь, в своём чате) → владелец решает, куда → владелец указывает получателю, что делать.
