# voice · профиль голоса автора

Статус профиля: предварительный (< 3 образцов) | рабочий | утверждён владельцем. Образцов: N.

| Измерение | Значение | Из каких образцов |
| --- | --- | --- |
| Длина фраз (среднее, разброс, ритм) | | |
| Длина абзацев | | |
| Лексика: любимые глаголы, связки, уровень формальности, оговорки | | |
| Цитаты и прямая речь: как вводит | | |
| Плотность определений и наречий | | |
| Сдвиги регистра по жанрам (техника / рассказ / письмо) | | |
| Чего автор никогда не делает | | |

Приоритеты при конфликте: факты и жанр (HARD) > площадка (STRONG) > личный стиль (SOFT). Конфликт логируется один раз на черновик.
