# 10-archive · архив

### Шаг 11. `10-archive/` — архив: ничего не удаляется

```
SYSTEM/10-archive/
  README.md                            правило: сюда переносится всё отменённое, заменённое, устаревшее — с датой и причиной; поиск по архиву разрешён; восстановление — по слову владельца
  <год>/<каталог-источник>/…           структура повторяет источник
  index.md                             что, когда, почему перенесено (генерируется)
```
- Пишет: только скрипт переноса по команде владельца; `index.md` — скрипт.
- Источник: правило владельца «ничего не удалять», C-7.A №20 (гигиена с подтверждением, «старое ≠ мёртвое»), kb-protocol (архивный тип проекта).
