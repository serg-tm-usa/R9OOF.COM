# 08-prompts · промпты и режимы

### Шаг 9. `08-prompts/` — база промптов и контексты режимов

```
SYSTEM/08-prompts/
  README.md
  catalog/                             промпты из каталогов (prompts.chat CC0 — локальная копия с датой; PromptHero, YouMind — выписки) с полями: источник, лицензия, дата, что изменили, где применили, результат
  own/                                 свои промпты по задачам; тот же формат записи; версии через новые файлы
  briefs/                              форма брифа (9 измерений замысла: задача, вход, выход, ограничения, контекст, аудитория, память, критерий успеха, примеры)
  contexts/                            режимы поведения для system-prompt: research.md, writing.md, engineering.md, review.md, archive.md — по 400–600 байт
  handoff-templates/                   шаблоны передачи между агентами и чатами: что сделано, что осталось, что сломано, следующий шаг
```
- Пишет: владелец и чаты; чужой промпт перед использованием читается целиком и проверяется на скрытые указания (правило T-49).
- Источник: T-49 (каталоги промптов как база), T-53 (prompt-master: 9 измерений), C-7.A №17 (contexts через system-prompt), C-6 handoff-templates.
