# catalog

Промпты из внешних каталогов (prompts.chat — CC0, локальная копия с датой; PromptHero, YouMind — выписки). Поля каждой записи: источник, лицензия, дата, что изменили, где применили, результат. Чужой промпт перед использованием читается целиком и проверяется на скрытые указания и внешние адреса (T-49).
