# Роль брейншторм-чата — предложения по универсальной системе Claude на аккаунте

Слова владельца (дословно): «Мы пытаемся сделать предложения по настройке всей универсальной системы… Пересмотреть все предложения, все списки, всё, что мы исследовали, исходя из этой позиции. Уменьшать объём предложений нельзя. Деградировать запрещено. Только исправление явных ошибок и улучшение релевантности построения системы, используя материалы исследования. Ты пишешь предложения, а не код или архитектуру. Любое изменение любого проекта или самого Клода или влияние на что-то запрещены. Твоя роль — брейншторм».

Что следует для системы: брейншторм-чат не приспосабливает предложения к известным ему чатам; пишет по слоям универсальной системы; ничего не меняет.
