# Общее правило: выбор модели по задаче

1. Детерминированное и мелкое (сортировка, извлечение, проверка формата) → быстрая модель; реализация → средняя; архитектура, судейство, факты, тексты для владельца → сильная.
2. Судья, ворота, проверяющий фактов, автор — сильная модель; сортировщик и сканер — быстрая.
3. Модель не пишется в файлы ролей и правил — только класс («сильная / быстрая»); подмена модели в сессии сообщается громко, не тихо.
4. Внешние модели других поставщиков не используются; «второй судья другого семейства» — только на закрытом контуре и по решению владельца.
5. Субагенты — ради экономии контекста; уточнение их ответов не больше трёх циклов; «достаточно хорошо» — остановка.
