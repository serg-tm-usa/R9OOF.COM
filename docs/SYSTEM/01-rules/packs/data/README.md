# Пакет `data`

Базы и журналы: миграции с парой up/down и dry-run, линт опасного SQL (DROP / TRUNCATE / DELETE без WHERE), индексы, проверка схемы, «нелегальные состояния непредставимы». Источники: C-8 ruflo-migrations, type-design-analyzer; C-7 database-reviewer.

Правила пакета пишутся файлами с frontmatter `paths:` или `packs:`; первая строка — «расширяет common/…»; каждое правило — с датой и источником; утверждает владелец.
