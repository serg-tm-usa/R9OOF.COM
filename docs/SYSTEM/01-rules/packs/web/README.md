# Пакет `web`

Сайты: **архитектор поисковой видимости в команде архитекторов с первого решения** (SEO, AEO, GEO, AIO, SXO, карты, каталоги, соцсети; указание владельца T-54, с промптом роли, контролем, метриками, местом в иерархии); заголовки безопасности (C-3, C-7 web/security); производительность и бюджеты (C-7 web/performance); доступность (C-6, C-7 accessibility); проверка перед запуском (ideas.md «20 пунктов»); C-1 «22 причины».

Правила пакета пишутся файлами с frontmatter `paths:` или `packs:`; первая строка — «расширяет common/…»; каждое правило — с датой и источником; утверждает владелец.
