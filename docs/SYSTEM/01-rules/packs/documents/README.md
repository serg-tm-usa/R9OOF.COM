# Пакет `documents`

Чтение PDF и сканов по лестнице достоверности (markitdown → pdftotext → … → OCR), уровни A/B/D, растр для чертежей и таблиц, подготовка сканов (Stirling-PDF, T-45), визуальный поиск (план `docs/pdf-visual/`). Источники: скиллы pdf-markitdown, engineering-source-discipline.

Правила пакета пишутся файлами с frontmatter `paths:` или `packs:`; первая строка — «расширяет common/…»; каждое правило — с датой и источником; утверждает владелец.
