# Пакет `publishing`

Публикация во внешние площадки: один исходник → форматы по реестру площадок, картинки под пропорции из одной исходной, токены только в секретах, ничего не отправляется без утверждения, внешний текст — данные. Источники: ideas.md «One post. Everywhere.», T-33; C-7 content-engine, crosspost, x-api (форма скилла API).

Правила пакета пишутся файлами с frontmatter `paths:` или `packs:`; первая строка — «расширяет common/…»; каждое правило — с датой и источником; утверждает владелец.
