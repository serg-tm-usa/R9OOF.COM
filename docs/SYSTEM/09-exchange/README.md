# 09-exchange · обмен с внешним миром

### Шаг 10. `09-exchange/` — обмен с внешним миром: закрытый GitHub, площадки, зеркала

```
SYSTEM/09-exchange/
  README.md
  github-private/                      что из системы уходит в закрытый репозиторий (всё, кроме `local/`), как версионируется; перед каждой копией — санитайзер (секреты, личные пути, ключи) и запись результата
  local/                               то, что никогда не покидает машину владельца: ключи, токены, личные данные, сырые сканы (перечислить в .gitignore корня)
  publishing/                          реестр площадок публикации: формат текста, пропорции картинок, способ отправки, где лежит токен (только в секретах), что запрещено публиковать
  mirrors/                             реестр внешних адресов (сайты, зеркала, API): проверка живости, заголовки безопасности, откат
  leaks-check.md                       регламент проверки собственных утечек (почта, домены) и реакции
```
- Пишет: владелец; санитайзер — скрипт с отчётом; `local/` — никто не копирует.
- Источник: решение владельца «папки на диске + копия в закрытом GitHub», C-7.A №18 (санитайзер), C-8 ruflo-chatgpt-federation § Key custody (ключ только файлом, без env), T-33 (площадки), T-32/T-32а (зеркала, заголовки), Onion/HIBP (T-50).
