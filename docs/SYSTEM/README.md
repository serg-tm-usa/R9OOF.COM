# SYSTEM · универсальная система Claude на аккаунте владельца

Каталоги по `docs/SYSTEM-PROPOSALS.md` §1, созданы 2026-10-08 по указанию владельца. Здесь — структура, README каждого каталога и заготовки первых файлов. Это предложения чата-брейншторма: ничего не подключено к Claude и ни на что не влияет, пока владелец не перенесёт и не включит.

Порядок чтения: `00-constitution/` → `01-rules/common/` → `02-agents/README.md` → `03-memory/schema.md` → `04-projects/README.md` → `05-gates/README.md` → остальное по необходимости.

| Каталог | Слой |
| --- | --- |
| `00-constitution/` | правила владельца, роли чатов, права записи (P0, пишет только владелец) |
| `01-rules/` | общие правила аккаунта и предметные пакеты |
| `02-agents/` | универсальные карточки агентов |
| `03-memory/` | якоря истины, сводки сессий, наблюдения, сгенерированное |
| `04-projects/` | слой проекта: brief, voice, glossary, facts, память, контроль, задачи, ADR |
| `05-gates/` | ворота самообучения и изменений правил |
| `06-checks/` | проверочные списки, схемы, тесты, базлайны, адверсариальный корпус, witness, отчёты |
| `07-tools/` | реестр инструментов, план установки и исследования, отчёты безопасности, MCP, согласия |
| `08-prompts/` | база промптов, бриф, контексты режимов, шаблоны передачи |
| `09-exchange/` | закрытый GitHub, локальное (не копируется), площадки, зеркала, утечки |
| `10-archive/` | всё отменённое, с датой и причиной |
| `11-journal/` | журналы: идеи, решения, задачи, аудиты, расходы, инциденты |

Три правила для всех каталогов: ничего не удаляется (отменённое помечается, заменённое — новым файлом со ссылкой); у каждого каталога записано, кто пишет (`00-constitution/write-rights.md`); сгенерированное машиной лежит отдельно от написанного человеком.
