# 07-tools · инструменты

### Шаг 8. `07-tools/` — инструменты: реестр, установка, отчёты безопасности

```
SYSTEM/07-tools/
  README.md
  registry.md                          реестр всех рассмотренных инструментов: имя, оригинальный источник, лицензия, вердикт (ставим / исследовать / образец / нет), дата, ссылка на разбор (checks.md, ideas.md); из C-5, C-7, C-8, ideas.md
  install-plan.md                      план установки и исследования (из ideas.md): порядок, способ (uv / Docker / плагин), выключатели телеметрии и сети
  profiles/                            профили установки: minimal (без хуков) / documents / engineering / web / archive — какие скиллы, агенты, пакеты правил входят
  manifests/                           манифест модулей: модуль = id, описание, целевые инструменты, пути; из него генерируются конфиги (не копируются руками)
  install-state/                       что и куда положено (чтобы всё можно было снять обратно); по инструменту
  security-reports/                    отчёт SkillSpector `--no-llm` по каждому скиллу/плагину/MCP до установки; история CVE; «что уходит в сеть»; без отчёта инструмент не ставится (правило 6)
  mcp/                                 карта MCP-серверов (предложение mcp-common-structure): хост / сервер, что слушает, пиннованные версии, политика default-deny
  consents.md                          таблица согласий владельца на автоматизации (хуки, сеть, фоновые задачи) с датой и версией политики; отказ тоже записывается
```
- Пишет: `registry.md`, `install-plan.md` — брейншторм-чат предлагает, владелец решает; `security-reports/`, `install-state/` — исполнитель и скрипты; `consents.md` — только владелец.
- Источник: ideas.md «План установки и исследования», C-5 правила безопасности 1–6, C-7.1 (манифесты, профили, dry-run, согласие на хуки, install-state), C-8.2 (выключатели и сеть), `docs/proposals/mcp-common-structure.md`, `host-server-separation.md`, SkillSpector (T-43).
