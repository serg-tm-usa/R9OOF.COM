### Общие правила безопасности (из аудитов OWASP Agentic Skills Top 10, Snyk ToxicSkills, Datadog)
1. Ставить только из оригинального репозитория автора, не с зеркал и перезаливок; у популярных есть фейковые копии (ECC, caveman, ui-ux-pro-max).
2. Перед установкой читать хуки и `settings.json`, которые инструмент добавляет; Claude Code исполнял хуки из клонированного репозитория до подтверждения доверия (CVE-2025-59536 и далее), держать Claude Code обновлённым.
3. Любой инструмент с прокси или сервером проверять: слушает ли только 127.0.0.1, есть ли проверка Origin, есть ли токен.
4. Телеметрию выключать явно (`DO_NOT_TRACK=1` понимают многие).
5. Каталоги (awesome-*) не ставят целиком: каждый скилл проверяется отдельно; по данным Snyk, в ClawHub 36,8% скиллов с уязвимостями.
6. (добавлено 2026-10-05) Проверка по п. 5 делается машинно: NVIDIA/SkillSpector, `scan <путь или URL> --no-llm`, отчёт Markdown прикладывается к решению об установке. Без отчёта инструмент не ставится. См. T-43.
