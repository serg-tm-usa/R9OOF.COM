## Проверки до работы (машина)
- входные файлы существуют и соответствуют схеме;
- слой проекта подан (brief, voice, glossary, facts) — иначе остановка;
- бюджет контекста и прогонов не превышен.

## Проверки после работы (машина)
- выходной файл есть, обязательные разделы на месте (линт структуры);
- факты: мультимножество чисел и имён до/после совпадает (если роль меняет текст);
- статус выставлен из разрешённого списка; «не запустилась проверка» записано как не запущено.
